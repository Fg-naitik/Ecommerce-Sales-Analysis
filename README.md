# 🛒 E-Commerce Sales Analysis

## 📌 Project Overview

This project performs exploratory data analysis on an e-commerce product dataset using Python and Pandas.

The goal is to understand product categories, stock levels, sizes, colors, and other patterns in the dataset through data cleaning, analysis, and visualization.

---

## 🎯 Objectives

- Clean and prepare the raw e-commerce dataset
- Analyze product categories and inventory
- Identify common sizes and colors
- Analyze stock distribution
- Find high-stock product designs
- Create meaningful data visualizations
- Extract useful insights from the dataset

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
